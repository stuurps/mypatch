# Development workflow

Before starting any session, read `WORKFLOW.md`.

**Mandatory on task completion — before ending the session:**
1. Check off completed items in `TASKS.md`
2. Create `releases/T[N]-[slug].md` using the release note format in `WORKFLOW.md`
3. Update `memory/project-patch.md` task progress

To pick a new task: read `BACKLOG.md` first, then follow the session prompts in `WORKFLOW.md`.
