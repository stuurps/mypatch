# Product direction

**North star:** quiet · personal · everyday · over time

**The test:** Does this deepen the user's relationship with one specific place? Would a birder mid-walk find this useful right now? Does it make the app feel calmer or busier?

**Patch is not:** eBird feature completeness, Merlin species ID, gamification, social features, streaks, badges, or anything that only pays off after 12 months of data.

# Development workflow

Before starting any session, read `WORKFLOW.md`.

**Mandatory on task completion — before ending the session:**
1. Check off completed items in `TASKS.md`
2. Create `releases/T[N]-[slug].md` using the release note format in `WORKFLOW.md`
3. Update `memory/project-patch.md` task progress

To pick a new task: read `BACKLOG.md` first, then follow the session prompts in `WORKFLOW.md`.
